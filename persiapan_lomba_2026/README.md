# 🚀 Checklist & Panduan Persiapan Berkas Lomba Guru Inspiratif 2026

Selamat! Folder ini dirancang khusus untuk memandu persiapan Anda langkah demi langkah dalam mengikuti **Program Guru Inspiratif Astra Honda 2026**.

---

## 📁 Struktur Folder Persiapan

* 📂 **`01_administrasi/`**  
  Menyimpan Surat Rekomendasi Kepala Sekolah, SK, Sertifikat, dan Formulir Pendaftaran.
* 📂 **`02_makalah_ppt/`**  
  Menyimpan draf teks naskah slide, materi presentasi, dan folder screenshot UI aplikasi (`screenshots/`).
* 📂 **`03_video_pendukung/`**  
  Menyimpan skenario/script video, catatan rekaman, dan tautan video.
* 📂 **`04_dokumen_pendukung/`**  
  Menyimpan foto kegiatan penggunaan aplikasi di sekolah, testimoni, dan data pendukung.

---

## 🗺️ Alur & Langkah Persiapan Awal (Dimulai Dari Mana?)

Untuk mempermudah dan mencegah kebingungan, kita membagi persiapan menjadi **4 Tahap Utama**:

```
[TAHAP 1: Administrasi] ➔ [TAHAP 2: Screenshot & Data] ➔ [TAHAP 3: Makalah PPT] ➔ [TAHAP 4: Video]
```

### 1️⃣ TAHAP 1: Berkas Administrasi (Langkah Pertama - HARI INI)
- [ ] **Surat Rekomendasi Kepala Sekolah:** Gunakan draf pada `01_administrasi/DRAFT_SURAT_REKOMENDASI.md`, cetak, dan minta tanda tangan/stempel Kepala SMAN 1 Gianyar.
- [ ] **Registrasi Online:** Buka link `bit.ly/Registrasi-GuruInspiratif-AstraHonda2026` dan isi data dasar.
- [ ] **Kumpulkan Dokumen:** Simpan scan SK Guru, Sertifikat Penghargaan/Pelatihan di folder `01_administrasi/`.

### 2️⃣ TAHAP 2: Pengumpulan Aset Aplikasi & Data (HARI KE-2)
- [ ] Ambil screenshot tampilan **Web Filament Admin** (Dashboard, Import Excel Jadwal, Presensi, Bebas Pustaka) dan simpan di `02_makalah_ppt/screenshots/`.
- [ ] Ambil screenshot tampilan **Mobile App Flutter** (Kartu Pelajar Digital, Presensi Geolocation).
- [ ] Catat data angka efisiensi (misal: jumlah user aktif, persentase keakuratan presensi, hemat waktu rekap).

### 3️⃣ TAHAP 3: Penyusunan Naskah Makalah PPT (HARI KE-3 s/d 5)
- [ ] Gunakan file `02_makalah_ppt/NASKAH_SLIDE_PRESENTASI.md` untuk menyusun narasi setiap slide.
- [ ] Pindahkan narasi dan screenshot aplikasi ke Microsoft PowerPoint (.pptx 16:9, max 20 slide).

### 4️⃣ TAHAP 4: Skenario & Video Pendukung (HARI KE-6 s/d 8)
- [ ] Gunakan panduan di `03_video_pendukung/SKENARIO_VIDEO.md` untuk pengambilan video kegiatan di SMAN 1 Gianyar.
- [ ] Edit video singkat (2-3 menit) dan upload sesuai ketentuan.
